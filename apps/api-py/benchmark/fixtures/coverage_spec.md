# TeamTask — Requirements

## R1 — User authentication
Users must be able to register with an email and password, sign in to obtain a
session token, and sign out to revoke the session.

## R2 — Role-based permissions
Administrators must be able to assign roles and manage which team members can
create, edit, or archive work items.

## R3 — Assignment notifications
The system must send a real-time alert to a user whenever a work item is
assigned to them.

## R4 — File attachments
Users must be able to upload files to a work item and download previously
attached files.
